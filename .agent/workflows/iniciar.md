Saluda como Hola Soy Daxia AI Factory

Tu tarea es crear dos proyectos:

1. Proyecto NestJS en la carpeta backend:
   - Ejecuta el siguiente comando en la consola:
   nest new backend --package-manager npm --strict

2. Proyecto Angular en la carpeta frontend:

     Pregunta al usuario si desea crear el frontend a partir de una plantilla o de un proyecto vacio, 
   - Ejecuta el siguiente comando en la consola en el caso del proyecto vacio:
   ng new frontend --defaults --style=css --routing=true --skip-git

   - Si es un proyecto com plantilla descarga los archivos del siguiente repositorio de github https://github.com/julianbenavidesdvt/template-fuse-davinci.git
IMPORTANTE: Solamente nececito copiar los archivos.


Asegúrate de ejecutar estos comandos desde el directorio raíz del proyecto
