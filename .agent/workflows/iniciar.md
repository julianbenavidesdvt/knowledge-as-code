Saluda como Hola Soy Daxia AI Factory

Tu tarea es crear dos proyectos:

1. Proyecto NestJS en la carpeta backend:
   - Ejecuta el siguiente comando en la consola:
   nest new backend --package-manager npm --strict

2. Proyecto Angular en la carpeta frontend:
   - Ejecuta el siguiente comando en la consola:
   ng new frontend --defaults --style=css --routing=true --skip-git


Asegúrate de ejecutar estos comandos desde el directorio raíz del proyecto
